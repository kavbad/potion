## Half-baked (a partner would notice)

| # | Seam | What's wrong | What fixes it |
|---|---|---|---|
| 1 | Classifier on short prompts | Clustering keys on surface vocabulary; a six-word prompt can land in the wrong cluster and get the wrong frontier | Embed with a short-prompt prior (instruction + first turn), and fall back to `potion-auto`'s platform frontier below a confidence floor |
| 2 | Savings vs the named incumbent | The receipt says "keeps 120%" of the bar; savings are vs list price of a premium model, not the partner's actual incumbent spend | Price the incumbent from measured usage; wording "matches or beats" |
| 3 | One floor per org | The quality floor is org-wide; a partner with support chat and code review wants a floor per kind of work | Per-cluster floors + "apply to all" from a proposal |
| 4 | "Other" incumbents | A model typed in the picker is recorded but never measured | Resolve typed models against the registry; measure when a transport exists |
| 5 | Roster duplicates | The same native model appears under two aliases in the incumbent picker | Dedupe by native id |
| 6 | Tool calls don't stream | Requests with `tools` still get the replayed burst (correct, not live) | Stream tool-call deltas once the strategy layer can assemble them |
| 7 | Writer on the OpenAI SDK | Proven, not merged — `openai@7` needs Node 22; the image is node:20 | Bump the image when the next base change lands |
