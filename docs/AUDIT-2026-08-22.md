- Found along the way: the production box OOM-killed `dockerd` during a combined image build (≈1 min of downtime, restored on existing images); 2 GB swap added, images now build one at a time.

- OpenAI wire parity (2026-08-23): agentic tool loops (assistant `tool_calls`, `role: "tool"`), content-part arrays, and the caller parameters (`temperature`, `top_p`, `stop`, `seed`, `user`, `response_format`, `parallel_tool_calls`) — found by reading the schema: every tool loop had 400'd on its second turn and `temperature` was accepted then never sent. Images refused with `unsupported_content`.
- Observatory rung 5: the coverage-ratchet report, refreshed weekly (first: roster 29 vs a line at 29.7).
- Classifier: held-out evaluation says 96% at the production threshold; the production margins say the authored held-out set is the wrong instrument — next is a production-derived, judge-labelled set (`docs/research/classifier-separation-2026-08-23.md`).
- Node 22 image.
- Reasoning models under small budgets (2026-08-23): learned from evidence in-process and skipped before the call below 1024 output tokens; the retry excludes them. Verified live: three JSON-mode requests at 300 tokens went empty → retried → straight to a model that answers (valid JSON, 248 tokens). Frontier Notes writer now on the official OpenAI SDK (proven live on copies).
- JSON mode at the edge (2026-08-23): models that ignore `response_format` through OpenRouter (or-opus) fence the object; non-streaming responses now unwrap a fence whose inside parses, so `JSON.parse` works as on OpenAI.
- Budget-blind frontier (2026-08-23): the extraction pick is a reasoning model that returns nothing under a customer-sized `max_tokens`, and Potion said `finish_reason: stop`. Shipped: finish reason passthrough and the empty-answer retry on the next point (`retry=empty_answer`). Measurement follow-up in `docs/research/budget-blind-frontiers-2026-08-23.md`.

## Order of work from here — the product/technology agenda (operator-approved 2026-08-23)

The seven walls, in attack order:

1. ~~**C — the router's tax**~~ measured and closed 2026-08-23: pipeline
   32 ms, classification 102–208 ms on a cache miss (`x-potion-timing`
   header, measured in-request), ~0 hinted/cached — Potion's whole toll is
   ~160 ms unseen / ~30 ms repeat. First-token time is the routed model's
   own warm-up; the lever is latency-aware routing. See
   `docs/research/router-tax-2026-08-23.md`.
2. **B — the map's freshness**: watcher LIVE; the reflow it triggered found the judge's fee folded into the serving cost axis — split shipped (0048), all ten frontiers rebuilt from cells at live prices and promoted (see docs/research/judge-fee-reflow-2026-08-23.md). Remaining: rewrite-edit cascade re-measure; auditions earning slots. Was: (nightly cron, first run
   2026-08-23 found 3 movers: deepseek +77%/+70%, deepseek-flash −37% —
   research-log alarm posted). Remaining: reflow the affected clusters
   (re-measure or re-price their points), and auditions earning slots.
3. **A — the brain's instrument**: the production-derived, judge-labelled
   held-out set the moment partner traffic exists; then margin-aware
   centroids and per-cluster thresholds, judged by margin distribution and
   the live tiebreak rate, not accuracy alone.
4. **G — multimodal**: PHASE 1 SHIPPED 2026-08-23 — the vision instrument
   (16 deterministic items), a measured vision frontier for extraction
   (six points; the cascade is frontier-optimal at 1.000 / $0.90), and
   serving live through the public API (`instrument=vision`; honest refusal
   names the cluster elsewhere). PHASE 2 same day: charts (rag-answer) and document types (classification) measured and serving; supports_vision learned onto the registry (0050). PHASE 3 same day: screenshots → code-gen measured (execution-scored) and serving — vision on FOUR clusters. Next: audio. See docs/research/vision-frontier-2026-08-23.md.
5. **D — the compounding asset**: MIXING M5 (per-org tuning of escalation
   thresholds on the org's own traffic) and M4 (parallel shapes that make
   mixtures interactive-fast); combination streaming.
6. **F — the trust chain**: a small monthly human-labelled sample re-anchoring
   the judges; drift in judge agreement alarms like quality drift does.
7. **E — resilience**: second replica, direct-provider failover for frontier
   picks, then a second region when an SLA demands it.

Exploratory, filed not scheduled: **quantum routing** (an "OpenRouter for
QPUs") — routing circuit jobs across quantum cloud providers (IBM, IonQ,
Rigetti, Quantinuum via Braket/Azure) on measured queue time, fidelity,
error rates and cost per shot. The measurement-first philosophy transfers
cleanly; the market today is research labs, the integration surface is
entirely different (circuits, not chat), and it would be a second product.
Worth a one-page landscape note before any code.
