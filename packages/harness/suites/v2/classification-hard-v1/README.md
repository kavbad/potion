# classification-hard-v1

classification-hard-v1 — the label is never recoverable from tone.
Six families of five. Each item states a decision rule and the answer
follows from applying it: an override that beats the obvious topic, a
tie-break the reviewer names, a numeric band with an exact boundary, an
attribution rule about whose opinion counts, an exception that inverts
the obvious call. Wrong answers come from skimming the rule.
