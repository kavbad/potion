# code-gen-hard-v2

code-gen-hard-v1 saturated: its champion stopped failing (1.000 across
salted runs, 2026-08-24), so a crown on it stopped meaning anything. v2
keeps all 30 v1 items (they still separate the mid-tier) and adds a
12-item frontier tier (cgh-f01..f12) of exact-specification contracts —
the failure mode frontier models still have is precision at spec
boundaries, not algorithm recall. Every reference is self-pass gated;
every item carries >=8 tests so fractional credit can rank near-misses.
